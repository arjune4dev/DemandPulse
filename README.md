# DemandPulse

End-to-end retail demand forecasting and inventory intelligence project.

## Folder structure

- `data/raw/` — original downloaded datasets (do not commit these to Git).
- `data/processed/` — cleaned datasets and feature tables.
- `notebooks/` — exploratory analysis and ML experiments.
- `src/` — reusable project code.
- `models/` — saved trained models.
- `reports/` — plots, evaluation results, and project notes.

## Getting started

1. Copy this folder to your Desktop if you want it located there.
2. Open it in JupyterLab.
3. Create your first notebook inside `notebooks/` named `01_data_understanding.ipynb`.
4. Download the Rossmann Store Sales `train.csv` and `store.csv` files into `data/raw/`.

Keep raw data and large model files out of GitHub unless you have a specific reason to share them.
